# Quick Start Guide

## Get Started in 3 Steps

### 1. Start the Backend Server
Open a terminal and run:
```bash
npm run server
```
You should see: `Server running on http://localhost:3001`

### 2. Start the Frontend
Open a **second terminal** and run:
```bash
npm run dev
```
You should see: `Local: http://localhost:5173`

### 3. Open the App
Open your browser and go to: **http://localhost:5173**

## Using the App

1. Click "Choose File" and select a video with speech
2. Enter your OpenAI API key (get one at https://platform.openai.com/api-keys)
3. Click "Generate Captions"
4. Wait for transcription (usually 10-30 seconds)
5. Watch your video with TikTok-style captions!

## Need Help?

- **No captions?** Make sure your video has clear speech
- **API error?** Check your OpenAI API key is valid
- **Server not starting?** Make sure port 3001 is available

See [README.md](README.md) for full documentation.
